# xG-Modelling

## Liam Hiles

### MSc Sports Analytics, University of Liverpool

This project was a university assignment, I developed and evaluated an expected goals (xG) model that predicts the probability of a shot resulting in a goal. Multiple candidate modelling workflows are compared using log-loss as an evaluation metric. The final model is applied to identify players who over/under-perform relative to their xG.
